# Voice workspace：完整需求与当前实现边界

目标是以语音为入口、支持长期思考和多分支延续的 workspace，并提供可复用的
上下文与记忆基础设施。产品范围保持完整，简历最后才从实际结果中提炼三条。
C++ 负责交互运行层；STT、文本推理、分段 TTS 和后台整理独立配置。

## 核心不变量

1. 临时转写不落为持久发言；最终转写与后台任务 outbox 同事务提交。后台
   整理尚未运行，近期发言也已可读取。队列投递失败可用同一 ID 重试。
2. 发言确认与长期记忆确认是两件事。候选不自动写入记忆；显式确认或修正
   产生带来源的新版本。过时任务不能覆盖已经变化的 key。
3. 新发言、打断、分支切换和重连推进持久 `epoch`。回复携带 session、branch、
   request ID、epoch 和上下文 revision；入队与 render 前重新验证。
4. 旧任务可以完成对原分支的候选提取，但必须经过版本检查和调用方确认；
   不能写入当前分支的音频队列。已结束的回复封口，额外迟到输出也被拒收。
5. Redis 是可重建缓存，不能成为权威事实。PostgreSQL + outbox 与
   SQLite 参考实现保持一致；Kafka 投递不假设 exactly-once。

## 上下文与恢复

- 近期发言与已播片段分别最多考虑最近 64 条，完整事件历史仍保留。
- 当前最终发言优先入包，其次是匹配的已确认记忆，再加入明确确认已播完的
  完整 assistant 片段。生成文本不自动成为长期记忆。
- 默认预算单位是 UTF-8 字节；传入 `token_counter` 才使用调用方的模型计数。
  需要另行预留模型 system prompt、模板和输出空间。最新发言装不下时拒绝开始回复。
- fork 复制当时的记忆和发言可见性引用；之后的父分支新发言不进入子分支。
  assistant 播放记录目前只在原分支恢复，不跨 fork 自动继承。
- `revoke` 从近期发言视图排除原发言，并阻止其候选被确认；它不是撤回已经
  确认的记忆，也不是音频/原始数据删除接口。修正已确认记忆用版本化 `correct`。
- render 只记录交给播放端的字节；客户端调用 `playback_ack` 才代表播放确认。
  offset 单调递增、不能超过 rendered。重连恢复 offset，但不自动重播旧音频。

## C++ 和协调层边界

C++ 有三个队列：采集字节、文本片段、播放字节；队列分别按 payload 字节和
item 数限制，文本 pending 与文本队列共享字节预算。返回背压时不静默丢包；
调用方需暂停、拆分过大块或等待消费。音频序号必须连续，同一文本 stream 的碎片必须按序到达；网络适配器负责重排。
目前缓冲按字节配置，音频格式确定后还需要换算为时长并验证 sample/frame 边界。

C++ 可从并发线程接收数据，但目前没有内建网络 SDK 或声卡线程。Python
`Conversation` 是单会话协调参考实现：provider I/O 在锁外进行，回调通过锁和
SQLite 事务串行检查状态；不要在协调锁外跨线程直接操作它持有的 Pipeline。它的 `render` 包含 SQLite 与 ctypes 开销，不能当作
硬实时声卡回调。真正设备路径应在 C++ 中消费队列并传播控制代次。

软件取消能清空尚未消费的队列，不能撤回已经交给硬件的字节。需要设备缓冲
大小、驱动取消与硬件播放确认，才能测量用户听到声音停止的实际时间。

## 模型调用、成本与失败

`STTProvider`、`TextProvider`、`TTSProvider` 在 `providers.py` 定义。适配器应携带
模型/配置版本的 `name`，提供 bounded chunks，并自行配置 SDK 超时与音频格式。
取消 Event 是协作信号；即使供应商忽略取消，迟到结果仍会被本地拒收。

调用前写入持久账本并扣除声明单位，失败不退款；重连不能重置会话预算。
重复 call ID 不再次执行外部调用。`reported` 与声明预算分开记录，不代表已
接入实际计费。发生“已扣预算但结果未知”的崩溃窗口时，保留 reserved 状态，
需要供应商幂等键或结果对账；不承诺外部 side effect exactly-once。

响应设置总文本/音频字节上限和协作式截止时间。检查发生在数据返回/阶段边界，
不抢占永久阻塞的 SDK。文本 provider 的 active iterator 时间与整段回复耗时
分开，TTS 时间包含等待播放队列的时间，STT 时间包含最终转写持久化。不能把
这些时间相加当作纯模型计算时间。

## 四组验收

| 指标 | 正确测量边界 |
| --- | --- |
| 交互 | 用户停止说话/最终转写到实际首段播放；打断到硬件停止；固定并发下的 p50/p95 |
| 上下文 | 跨会话与分支恢复、检索、否定/修订、压缩质量；用独立标注数据评估 |
| 可靠性 | 最终发言更新延迟、重复/乱序正确性、投递失败与重启恢复；保留失败原始结果 |
| 成本 | 固定场景和质量条件下真实 STT/文本/TTS/后台费用，计入失败、重试和路由 |

C++ 性能实验固定输入与 provider；模型策略实验固定运行层与任务。脚本化
byte payload、软件队列延迟和声明单位，分别不等于语音、扬声器延迟和真实费用。
